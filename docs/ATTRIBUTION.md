# Collaboration and attribution

HealthEase was developed collaboratively. This repository is Sangat Singh's separately maintained personal copy of that work; it is not a claim that the entire project was authored by one person.

The original local Git history credited **Jainish Jain** as the author of its initial commit. **Sangat Singh** is credited with the subsequent GitHub preparation commit and maintains this personal copy. These commit records establish the recorded provenance, not an exhaustive list of everyone who contributed. The complete original project and Git history are retained in a private local backup.

The personal repository starts with fresh Git history as requested by its maintainer. Removing the previous commit graph does not remove the original contributors' credit, copyright interests, or license requirements.
